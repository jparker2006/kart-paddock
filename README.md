# Kart Paddock

A small three-game playtest launcher. Builder identities are hidden until Reveal models is pressed. These early a/b route labels are not the final five-entry blind assignment. The page does not provide rankings.

The games are copies of the frozen Astra, Fable, and GLM submissions. No gameplay code is modified. The static Vercel output contains only the launcher and compiled clients; source, run records, and backend code are not uploaded to the public site.

## Deployment

Use Node 24.20.0 and npm 11.19.0. Each game runs in its own single-instance Render Free service, using render.yaml. Set each ALLOWED_ORIGINS to the exact Vercel production origin. Do not add a wildcard. Render supplies PORT; HOST is 0.0.0.0. Services use in-memory rooms and lose them on restart.

Build the static site using the actual backend URLs:

```sh
GAME_A_SERVER_URL=https://kart-paddock-a.onrender.com GAME_B_SERVER_URL=https://kart-paddock-b.onrender.com sh scripts/build.sh
vercel link --project kart-paddock
vercel deploy --prebuilt --prod
```

The exact public aliases must be confirmed from provider output. A preview origin also needs to be explicitly allowed on both servers before its games can connect.

Render Free services may sleep after 15 idle minutes, take about a minute to wake, and restart. Multiple free services share the workspace's 750 monthly instance hours. No paid plan or add-on is part of this setup.

Game paths: /games/a/ and /games/b/. Framed play views: /play/a/ and /play/b/. Invite links generated by each game open its direct game path. The full-window action also opens the direct path.
