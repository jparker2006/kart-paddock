# Asset sources

| Asset | Source | Attribution |
| --- | --- | --- |
| Track, bridge, ramp, island, buildings, palms, boats, balloon, clouds, crates | Original procedural Three.js geometry in `src/client/world.ts` | No external asset attribution |
| Delivery karts, drivers, parcel pickups, particles | Original procedural Three.js geometry in `src/client/world.ts` | No external asset attribution |
| Signs and driver labels | Original locally generated Canvas2D textures | No external asset attribution |
| Map, logo, interface styling | Original Canvas2D, text and CSS | System font stack; no downloaded fonts |
| Engine tone and cues | Original Web Audio oscillator synthesis in `src/client/main.ts` | No external audio attribution |
| Three.js | https://github.com/mrdoob/three | MIT; license in installed package |
| Socket.IO and Socket.IO client | https://github.com/socketio/socket.io | MIT; licenses in installed packages |

All art and sound assets were created as code by this session's assigned model. No external AI generation service or other model was called. Package dependencies and test browser binaries came from their registries or official distribution endpoints. Test browser binaries are verification tools, not game assets, and are excluded from version control.
